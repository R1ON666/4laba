# Библиотека: импорт/экспорт книг в JSON (Django)

Вариант 1 — информация о книгах, формат JSON.

## Запуск
```bash
pip install -r requirements.txt
python manage.py runserver
```
Откройте http://127.0.0.1:8000/

## Возможности
- ввод книги через форму с валидацией (ISBN с контрольной суммой, год, страницы и т.д.) -> JSON-файл;
- загрузка JSON-файлов с проверкой; невалидный файл удаляется, имя файла генерирует сервер (uuid);
- вывод содержимого всех файлов из `data/books/`, сообщение, если файлов нет;
- скачивание файла и экспорт всех книг одним JSON.

## Структура
`manage.py`, `settings.py`, `urls.py`, `views.py`, `forms.py`, `storage.py`, `wsgi.py`, `templates/`
